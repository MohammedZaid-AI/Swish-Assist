    // the problem

    A 10-minute delivery followed by a 30-minute support wait undoes the magic.

    01Wrong or missing items

    An agent reads every complaint, checks the order and decides each refund by hand.

    02Slow or no replies

    Evenings fill the queue with "where is my food?" while customers wait.

    03Coupons that confuse

    "Why didn't my coupon apply?" needs someone to read the rules for every order.

    // how a photo complaint is handled

    Cheapest checks first. The vision model only runs when it has to.

    01 · freeFraud checks

    Duplicate photo hash, complaint timing, refund history and the photo's EXIF date. Any flag goes straight to a human.

    02 · ~2 sVision check

    A Groq vision model compares the photo with the order and reports what's missing, with a confidence for each item.

    03 · instantRefund or hand off

    Confident cases under ₹300 are refunded on the spot. The rest reach a human with a 10-second summary.
